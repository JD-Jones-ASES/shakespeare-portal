## Pipeline & process history

**Pipeline proven on twenty-three plays** (four pilots + all ten English histories + the four romances + three framing/pageant comedies + the first two Roman tragedies — the Henriad *Richard II–Henry V*, the complete first tetralogy *Henry VI Parts 1-3 + Richard III*, the two outliers *King John + Henry VIII*, and *The Taming of the Shrew + Love's Labour's Lost + The Comedy of Errors*): ingest → Sonnet annotator subagents → deterministic anchor resolution (`resolve-anchors.ts`, shared matcher in `lib/text.ts`) → adversarial fact-check (source + interpretation Sonnet judges + deterministic anchor judge, merged by `apply-verdicts.ts`) → validators → Astro reader. Glossary uses the same generate→fact-check pattern (`merge-glossary.ts`, `apply-glossary-verdicts.ts`). **`reanchor.ts`** re-resolves shipped annotations after a re-ingest so TLN shifts don't break anchors. All 3 validators pass; the site builds. Julius Caesar was run via the **Workflow** tool (one annotator subagent per scene → source+interp judges per scene), then the deterministic merge steps run serially from inside `scripts/` (must use `node --import tsx …` from `scripts/`; `node`'s `execFileSync` can't spawn the `.bin/tsx.cmd` shim on Windows — EINVAL). Romeo and Juliet ran the same way (24 annotators + 48 judges, then a 5-act glossary fan-out). The `workflows/annotate.mjs` and `workflows/glossary.mjs` templates were hardened to accept `args` delivered as a JSON **string** as well as an object (`const input = typeof args === 'string' ? JSON.parse(args) : args`) — without it the Workflow tool can throw "Workflow args must be…" before any agent runs. **Session 2** (H4.2 + Henry V) added an optional `guidance` arg to both Workflow templates (appended to every annotator/lexicographer prompt) — used for Henry V's French-translation instructions and the French-glossary exclusion; it is the reusable hook for H6.1's Joan. **Concurrency lesson:** running the two plays' heavy annotate Workflows *concurrently* (~126 agents) saturated the machine and ~55-60% of later-scene annotator agents finished WITHOUT writing their candidate files (the workflow still reports all agents "completed"); the candidate files were simply missing (not malformed). Re-running the missing scenes **one workflow at a time** fixed it cleanly. **Rule: at most one heavy annotate Workflow at a time** (a light ~5-agent glossary Workflow alongside is fine). The `_check-candidates` / unmapped-speaker / detail-summary-fix helpers were throwaway diagnostics (recipe in memory `henriad-b-build-notes`). **Session 4** (Henry VI Part 3 + Richard III) re-confirmed the concurrency rule — one heavy annotate + one light glossary per play, sequential across plays — with **0 candidate loss (290/290 and 373/373)**. **Session 5** (King John + Henry VIII) confirmed it a 4th time (259/259 and 319/319, 0 loss) and cleared **all four outstanding `_review_queue/`s in a single 4-agent Opus rescue Workflow — 83 items rescued, 0 cut** (John 20 + Henry VIII 21 + the deferred Henry VI Part 3 20 + Richard III 22) via `scripts/pipeline/_merge-rescued.mjs`; one rescued classical citation (the Olympian games, correctly re-sourced to Pindar/Pausanias) prompted adding those two ancient authors to the citation allowlist. **Session 6** (The Tempest + Pericles — the first romances) confirmed the concurrency rule a 5th time (**0 candidate loss**: Tempest 9/9 scenes, Pericles 22/22) and for the first time *overlapped* a heavy annotate with a light glossary within the rule (Pericles annotate ~66 agents + glossary 5 agents, peak ~21 concurrent — fine). Also folded in the Phase-C **Titus source-path alias** (`scripts/lib/paths.ts` `MODERN_SOURCE_ALIAS`: `titus_andronicus` → `tragedy_of_titus_andronicus_gut.txt`), unblocking the eventual Titus build. **Session 7** (Cymbeline + The Winter's Tale) confirmed the concurrency rule a 6th time (**0 candidate loss**: Cymbeline 27/27, Winter's Tale 15/15; each heavy annotate overlapped with its own light glossary, peak ~21 concurrent) and cleared both new queues with the 2-agent Opus rescue Workflow (**49 rescued, 0 cut**) — one rescued Apollo-oracle citation again needed an allowlisted ancient source (Herodotus/Pausanias on Delphi). ## Known limitations — parser history (per-play gated normalizers)

Cross-cutting limitations (#1–5: anchor word-granularity, subagent-JSON quoting, gitignored `_*`
files, Windows/Astro glob cache, the unclosed-`[` guard) stay in `CLAUDE.md`. The per-play gated
parser normalizers below are historical detail; each was verified **byte-identical for prior shipped
plays** via the re-ingest regression diff.

- **(6) Henry VI edition normalizer.** The Open Shakespeare **Henry VI** transcription uses a different convention — ordinal/no-period act headers (`ACT FIRST`), scene settings on the line *after* the SCENE header (so `Westminster Abbey.` was misread as a speaker), and many *unbracketed* stage directions (`Dead March. Enter the funeral...`). The **slug-gated** `normalizeHenryVIEdition` in `parse-gutenberg.ts` folds separate-line settings into the SCENE header and wraps an unbracketed-SD block ONLY when its first line is a high-confidence stage cue (Enter/Exeunt/Alarum/Flourish/Dead March/etc.), so a dialogue continuation after an in-speech blank line is never swallowed; the 8 prior plays re-ingest byte-identical. Added `Herodotus` to the citation allowlist (Charles's Rhodope, 1H6 1.6).
- **(7) Inline stage direction at the START of a dialogue line** (`[Aside.] Not I.`, 3H6 4.1; cf. Hamlet's Ghost `[Beneath.] Swear.`): the short reply looks like a speech prefix, and because `emitSD` sets `expectSpeaker`, the trailing words were misread as a phantom speaker and the line lost. Fixed in `parse-gutenberg.ts` (`dispatchText` no longer treats text *after* an inline SD as a possible speaker), **gated on the Henry VI slugs** (`INLINE_SD_GUARD`) so the 10 already-shipped plays re-ingest byte-identical — verified (Hamlet's 4 Ghost 'Swear.' cries are intentionally left as-is; correcting them would shift Hamlet's TLNs and break its shipped annotation anchors). Richard III ingests clean without the guard, so it stays off there.
- **(8) Henry VIII / King John quirks (Session 5, all gated so the 12 prior plays re-ingest byte-identical).** Henry VIII's `THE PROLOGUE.` is followed directly by verse with NO Chorus speaker label (unlike Romeo and Juliet / Henry V), so the buffered prologue had no speaker and would be dropped; fixed by attributing it to a `Prologue` chorus when the play defines a `PROLOGUE.` alias (`hasPrologueSpeaker`), while the closing bare `EPILOGUE` reads as an `Epilogue` chorus through the existing SONG_HEADER-alias path. Henry VIII also occasionally prints an inline speaker label opening a shared verse-line (`NORFOLK. I thank your Grace,`, 1.1) — split off as a new speaker, gated `INLINE_SPEAKER_GUARD = slug === 'henry_viii'`. King John needed a no-dot `CONSTANCE` alias (the source drops the period at line 1622, else her 3.1 speech merges into Elinor's) and a `looksLikeSpeaker` tweak so a unison prefix (≥2 dotted ALL-CAPS known aliases, e.g. `PEMBROKE. and BIGOT.`) is accepted regardless of length — JC's 18-char cap had rejected the 20-char unison (self-gating: requires this play's aliases). Added `Pindar` and `Pausanias` to the classical citation allowlist (the Olympian games, 3 Henry VI 2.3, re-sourced during the rescue sweep). Regression-verified: re-ingesting all 12 prior plays changes only the date stamp (save the documented R2-DUCHESS / H4.1-GLEND post-ingest cleanups, which revert on a naive re-ingest and are restored with `git checkout`).
- **(9) Pericles' per-act Presenter, Gower (Session 6, slug-gated to `pericles`).** Pericles is framed by the medieval poet Gower, who speaks a rhymed chorus before every act — introduced by `[Enter Gower]`, in Act I with NO speaker label and in Acts II-V with a `GOWER.` label — plus mid-act interludes (4.4, 5.2) and the closing Epilogue, several carrying **dumb-shows**. The Romeo/Henry V chorus-buffer machinery was generalized: `emitSD`'s `enter chorus|rumour` trigger now also fires on `enter gower` **only at act-open** (`lastSceneNum === 0`), so the act-opening chorus buffers and prepends to the act head (and the label-less Act I verse is attributed to Gower by presetting `curSpeaker`), while Gower's mid-act / Epilogue appearances stay in their own numbered scene. An unbracketed `DUMB SHOW.` header (Act II) is rendered as a stage direction (it otherwise parses as a 2-word speaker); the other dumb-shows are bracketed `[Dumb Show.]` and need no case. **Gated `slug === 'pericles'`, NOT an alias check** — Henry V (Captain Gower) and Henry IV Part 2 (a messenger Gower) both define a `GOWER.` alias, so an alias-only gate would have wrongly fired on those shipped plays. Typo speaker-variants are aliased in `characters.json` (`PERACLES.`→Pericles, `HELCANUS.`/`HELICANE.`→Helicanus, `BARD.`→Bawd). Regression-verified byte-identical across all 14 prior shipped plays. **The Tempest needed NO parser change** (its masque deity-speakers Iris/Ceres/Juno are pure `characters.json` aliases). This generalized chorus machinery is the hook for Session 7's **Time-as-Chorus** (Winter's Tale 4.1).
- **(10) Titus source-path alias (Session 6 Phase-C fix):** `scripts/lib/paths.ts` now maps the slug `titus_andronicus` → the vendored `tragedy_of_titus_andronicus_gut.txt` via `MODERN_SOURCE_ALIAS`; all other slugs are unchanged.
- **(11) Cymbeline's modern vendored source was INCOMPLETE — repaired from Moby XML (Session 7).** The vendored `texts/gutenberg/cymbeline_gut.txt` (Open Shakespeare) is missing Acts III and IV — the entire Welsh storyline (Belarius's cave, Guiderius/Arviragus, Milford-Haven, the 'Fear no more' dirge, Cloten's beheading): the text jumps straight from 2.5 to 5.1 (and its combined `ACT II. SCENE I.` headers are malformed). Rather than edit the read-only vendor dir (Hard Rule #1), the complete public-domain **Moby Shakespeare XML** (`texts/moby/cymbeline_moby.xml`) was converted to standard `_gut.txt` form by `scripts/pipeline/_moby-to-gut.mjs` (a gitignored `_` helper: maps `<ACT>/<SCENE>/<TITLE>`→headers, `<STAGEDIR>`→`[..]`, `<SPEAKER>`→ALL-CAPS label joining unison speakers, `<LINE>`→text) and committed as `data/sources/cymbeline_gut.txt`; `gutenbergModernPath` returns it via a slug-gated `FULL_SOURCE_OVERRIDE` (one key: `cymbeline`). The converted text uses the standard `ACT I.`/`SCENE I. <setting>` + bracketed-SD + ALL-CAPS-speaker shape, so **no parse-gutenberg change was needed** and all 16 prior shipped plays re-ingest byte-identical (verified — only the date stamp + the documented R2-DUCHESS / H4.1-GLEND reverts differ).
